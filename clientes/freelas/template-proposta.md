# Template de Proposta

## Versão 1 — Profissional (para email / LinkedIn)

```
Assunto: Website para [Nome do Negócio]

Olá [Nome],

Espero que esta mensagem o encontre bem.

Vi que o [Nome do Negócio] ainda não tem presença online
— ou que o site atual poderia ser mais moderno e funcional.

Sou desenvolvedor web e ajudo pequenos negócios a marcarem
presença digital com websites profissionais, landing pages
e sistemas simples.

Trabalho com HTML, CSS, JavaScript, Firebase e Node.js.

Fiz sites para [exemplo 1], [exemplo 2] e [exemplo 3]
— todos com resultados comprovados.

Gostaria de fazer uma proposta sem compromisso para o
[Nome do Negócio]. Podemos marcar uma call rápida?

Fico à disposição.

Melhores cumprimentos,
[Teu Nome]
[Link do portfólio]
[WhatsApp]
```

## Versão 2 — Curta (para WhatsApp / Redes sociais)

```
Olá [Nome]! Tudo bem?

Sou desenvolvedor web e estou a ajudar pequenos negócios
a terem uma presença digital profissional.

Crio sites, landing pages e sistemas simples.

Tens interesse em saber como posso ajudar o
[Nome do Negócio]?

Se quiseres, posso enviar uma proposta rápida sem compromisso.

[Teu Nome] — [Link portfólio]
```

---

## Checklist para personalizar

- [ ] Substituir [Nome] pelo nome da pessoa
- [ ] Substituir [Nome do Negócio] pelo negócio alvo
- [ ] Escolher versão curta ou longa conforme o canal
- [ ] Mencionar algo específico do negócio (torna a proposta mais pessoal)
- [ ] Anexar link do portfólio ou de projeto relevante
