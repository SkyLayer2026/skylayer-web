# 5. Operação

## Fluxo comercial

```
Lead → Primeiro contacto → Reunião marcada → Diagnóstico → Proposta enviada → Negociação → Contrato → Em desenvolvimento → Entregue → Suporte → Cliente recorrente
```

### Regras do fluxo comercial

1. **Todo cliente passa obrigatoriamente pelo CRM** — nenhum lead fica fora do registo.
2. Resposta ao primeiro contacto: **máximo 2 horas** em horário útil.
3. Diagnóstico é feito antes de qualquer proposta.
4. Cada estado do CRM tem um checklist associado (ver `09-comercial.md`).
5. Propostas são enviadas com prazo de validade (ex: 14 dias).

## Fluxo interno de projeto

```
Planeamento → Design → Desenvolvimento → QA → Entrega → Documentação
```

### Estados do projeto

```
Planeamento → Design → Desenvolvimento → Testes → Revisão → Entrega → Concluído
```

### Ficha de projeto

Todo projeto tem: código (ex: `SKW-001`), responsável, estado, checklist, documentação, prazo, prioridade.

### Regras do fluxo interno

1. Nenhum projeto passa de fase sem o checklist da fase atual concluído.
2. Todo projeto tem documentação de entrega (o que foi feito, como usar, como manter).
3. Backups são feitos antes de cada entrega.
4. Atrasos são comunicados ao cliente antes do prazo — nunca depois.

## Revisões

| Frequência | Âmbito |
|---|---|
| Semanal | Operações (tarefas, prazos, leads) |
| Mensal | Resultados (receita, KPIs, clientes) |
| Trimestral | Estratégia (serviços, canais, roadmap) |

## Dashboard diário

Todas as manhãs, em menos de 2 minutos, deve ser possível responder:

- Quantos clientes existem?
- Quantos projetos estão ativos?
- Quanto se espera faturar este mês?
- Quanto tempo cada projeto está atrasado?
- Que tarefas são prioridade?
- Que clientes precisam de atenção?
