# 3. Produtos

> Definição: soluções padrão, construídas uma vez e reutilizadas várias vezes (biblioteca Skylayer).
> O objetivo é nunca começar um projeto do zero.

## Website Empresarial

| Campo | Valor |
|---|---|
| Objetivo | Presença profissional que converte visitantes em contactos |
| Público | PMEs sem site ou com site desatualizado |
| Prazo típico | 1–3 semanas |
| Tecnologias | HTML, Tailwind CSS, JavaScript/React, Vite |
| Modelo de preço | Fixo a partir de 7.000 MZN |
| Inclui | 1 página inicial + até 5 páginas, formulário de contacto, WhatsApp, responsivo, SEO básico, documentação |

## Sistema de Gestão Interna (dashboard/CRM simples)

| Campo | Valor |
|---|---|
| Objetivo | Substituir planilhas/WhatsApp na gestão de clientes, vendas, tarefas |
| Público | Pequenas empresas que gerem tudo no WhatsApp ou papel |
| Prazo típico | 3–8 semanas |
| Tecnologias | Node.js, PostgreSQL/SQLite, React, Docker, n8n |
| Modelo de preço | Projeto + manutenção mensal |
| Inclui | Login, gestão de clientes, dashboard, formulários, documentação, testes |

## Checklist de lançamento de produto

- [ ] Objetivo e público definidos
- [ ] Preço e condições definidos
- [ ] Landing page publicada
- [ ] Processo comercial definido (fluxo do lead)
- [ ] Testes de qualidade feitos
- [ ] Documentação criada
- [ ] Entrada no catálogo e no changelog
