# 15. Ferramentas

> Todas as ferramentas são gratuitas (ou têm edição gratuita suficiente).

## Sistema

| Área | Ferramenta |
|---|---|
| Sistema Operativo | Linux Mint |
| Editor de código | VS Code |
| Controlo de versão | Git + GitHub |
| Documentação | Markdown + Git |
| Gestão de projetos | OpenProject Community / Plane (self-hosted) |
| Base de conhecimento | MkDocs Material ou Docusaurus |
| Base de dados | PostgreSQL / SQLite |
| Backend | Node.js + Python |
| Frontend | HTML, Tailwind CSS, JavaScript/React |
| Design | Penpot |
| Diagramas | Draw.io |
| API | Bruno |
| Browser de BD | DBeaver Community |
| Containerização | Docker |
| Automatização | n8n Community |

## Regras de adoção de ferramentas

1. Gratuita/open source sempre que atender aos requisitos (princípio 2).
2. A ferramenta adapta-se ao fluxo da Skylayer, não o contrário.
3. Ferramenta nova só entra se resolver um problema real e for documentada aqui.
4. Ferramentas em fim de vida ou com custo crescente são revistas trimestralmente.
