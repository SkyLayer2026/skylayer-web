# 16. Roadmap

## Curto prazo (0–3 meses)
- [x] Estratégia e MOS v1.0
- [x] Repositório Skylayer criado
- [ ] Website institucional publicado
- [ ] Landing pages por serviço
- [ ] Processo comercial em uso (lead → contrato)
- [ ] Diagnóstico gratuito como lead magnet
- [ ] Primeiros clientes (contacto direto, indicações, networking)
- [ ] Pagamentos definidos (M-Pesa/bancário) e testados

## Médio prazo (3–6 meses)

- [ ] Validar oferta: notar quais serviços vendem mais e quais objeções surgem
- [ ] Portfólio real com depoimentos e estudos de caso
- [ ] Medir CAC e valor médio por cliente
- [ ] Primeiras campanhas de tráfego pago (com landing page própria)
- [ ] SEO básico no blog

## Longo prazo (6–24 meses)

- [ ] Biblioteca Skylayer sólida (design, código, comercial)
- [ ] Agentes de IA operando de forma estável sobre a base de conhecimento
- [ ] Dashboard executivo funcional (responder 6 perguntas < 2 min)
- [ ] Primeira contratação humana (o sistema é desenhado para receber pessoas)
- [ ] Sistemas clientes em manutenção recorrente (receita mensal previsível)

## Regras do roadmap

- Atualizado trimestralmente na revisão de estratégia.
- Itens só passam de fase com evidência (cliente, métrica, entrega).
