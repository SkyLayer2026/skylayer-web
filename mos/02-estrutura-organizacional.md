# 2. Estrutura Organizacional

A Skylayer não se organiza por departamentos. Organiza-se por **processos**.

```
Captação → Diagnóstico → Proposta → Produção → Qualidade → Entrega → Suporte → Melhoria contínua
```

Cada processo tem: procedimentos, templates, checklists, agentes de IA especializados e responsabilidade humana na aprovação.

## Funções humanas

| Função | Responsabilidade |
|---|---|
| Estratégia e decisões críticas | 100% humano |
| Relação com clientes | 99% humano |
| Design e direção criativa | Humano (com apoio IA) |
| Desenvolvimento | 70% humano (agentes fazem o resto, sob revisão) |
| Aprovações finais | Sempre humano |

## Agentes de IA

| Agente | Função principal |
|---|---|
| SL Strategy | Estratégia, decisões, análise |
| SL Comercial | CRM, prospecção, propostas |
| SL Marketing | Campanhas, blog, LinkedIn |
| SL Técnico | Código, documentação, revisão |
| SL Pesquisa | Concorrência, tendências, tecnologias |
| SL QA | Testes, qualidade, auditoria |

Todos os agentes trabalham sobre a mesma base de conhecimento (MOS + biblioteca Skylayer).

## Regra de ouro

> Nenhum agente toma decisões críticas sozinho. Todo resultado de IA passa por revisão humana antes de ser usado com clientes.
