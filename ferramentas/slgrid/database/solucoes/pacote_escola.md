# Pacote Escola / Laboratório de Informática

**Ideal para:** Escolas, centros de formação, institutos

---

## O que inclui

### Hardware
- **15x Computador Lenovo / Dell** com monitor 21.5"
- **1x Servidor de Arquivos** (Dell PowerEdge ou HP ProLiant básico)
- **1x Impressora HP LaserJet** (multifunções, rede)
- **2x UPS APC 1500VA** (servidor + laboratório)

### Rede
- **1x Switch Gigabit 24 portas** (TP-Link ou D-Link)
- **3x Access Point TP-Link EAP610** (cobertura total)
- **Cablagem estruturada Cat6** (laboratório + admin)
- **Rack de parede 12U**

### Serviços
- Instalação e configuração
- Configuração de rede Wi-Fi
- Servidor configurado (arquivos + backup)
- Formação para professores (4h)
- Suporte por 60 dias
