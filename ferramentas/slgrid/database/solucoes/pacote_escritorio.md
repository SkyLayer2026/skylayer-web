# Pacote Escritório Pequeno

**Ideal para:** Pequenas empresas, escritórios, consultórios

## O que inclui

### Hardware
- **5x Computador Lenovo ThinkCentre / Dell Optiplex** com monitor 22"
- **1x Impressora HP LaserJet Pro M404dn** (laser preto, duplex, rede)
- **1x UPS APC Back-UPS Pro 1500VA** (proteção para todos os equipamentos)
- **1x Switch TP-Link TL-SG108** (rede Gigabit)

### Rede
- **1x Access Point TP-Link EAP610** (WiFi 6 profissional)
- **Cablagem estruturada Cat6** para todos os postos
- **Rack de parede 6U**

### Serviços
- Instalação e configuração de equipamentos
- Configuração de rede Wi-Fi
- Instalação de software base
- Formação básica dos utilizadores (2h)
- Suporte por 30 dias
