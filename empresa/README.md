# empresa/ — Documentos internos da Skylayer

Documentos internos. **Este conteúdo nunca é publicado no repositório público.**

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `clientes/` | Documentos por cliente: Katembe (medidas de projeto), MISAU (materiais PrEP) |
| `contratos/` | Modelos de contrato, cotações, termos e condições |
| `correspondencia/` | Cartas, ofícios e correspondência institucional |
| `financas/` | Cobranças e tabela de preços. Nota: existem várias versões de `cobrancas04*` — verificar qual é a versão em uso antes de editar |
| `marketing/` | Leads, prospeção, mapeamento de nichos e estratégias de vendas |
| `operacoes/` | Registos operacionais (ex: recolha de equipamentos) |
| `tutoriais/` | Guias internos (Joomla, WordPress) |

## Segurança

- Este diretório está fora do repositório público (`SkyLayer2026/skylayer-web`).
- `financas/`, `marketing/` e `clientes/` contêm dados sensíveis (valores, contactos de leads, contratos).
- Backup: `~/skylayer/legado/backup-2026-01-18/` preserva o estado anterior à reorganização.
