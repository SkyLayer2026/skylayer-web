# Skylayer

Empresa de tecnologia — democratizar a transformação digital.

| Item | Valor |
|---|---|
| Fundação | Dia 1 (2026) |
| Equipa inicial | Humano + Agentes de IA |
| Sede | Moçambique |
| Modelo | IA-first, pequena em pessoas, ampliada por agentes |

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| `mos/` | Manual Operacional da Skylayer (Markdown, versionado) |
| `web/` | Website institucional + landing pages (Vite + React + Tailwind) |

## Princípio central

> Se uma tarefa precisa ser executada duas vezes, ela deve ser documentada.
> Se precisa ser executada muitas vezes, deve ser padronizada.
> Se for repetitiva, deve ser automatizada.

## Início rápido

```bash
# Website (dev)
cd web && npm install && npm run dev

# MOS — apenas editar os ficheiros .md e commitar
```
